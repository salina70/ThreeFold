# Feedback Nepal

AI-powered customer feedback analyzer for businesses in Nepal.

## Live Demo

👉 http://localhost:3001

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- JWT Authentication
- Axios
- Tailwind CSS

## Features

- Browse businesses
- Search and filter businesses
- Customer reviews
- Star ratings
- User authentication
- Business owner dashboard
- AI-powered feedback analysis

## Solution

- Customers can discover and review businesses.
- Businesses can monitor customer reviews.
- Reviews can be analyzed using AI.
- Ratings help businesses understand customer satisfaction.
- Business owners can identify common problems and improve their services.
